# SQL Data Analytics Project

A comprehensive SQL-based data analytics project focused on exploring, cleaning, analyzing, and reporting data using Microsoft SQL Server.

This repository contains SQL scripts that demonstrate practical data analytics techniques, from database exploration and data quality checks to advanced analytical queries and business insights.

## 📌 Project Overview

The goal of this project is to demonstrate how SQL can be used to transform raw relational data into meaningful insights.

The project covers different stages of the data analytics process, including:

* Database exploration
* Data quality and validation checks
* Data cleaning and transformation
* Exploratory data analysis (EDA)
* Business metrics and KPIs
* Time-based analysis
* Cumulative analysis
* Customer and product segmentation
* Ranking and analytical functions
* Reporting and business insights

## 📊 Key SQL Concepts Demonstrated

### Database Exploration

Queries for understanding database structure, tables, columns, records, and relationships.

### Data Cleaning

Techniques for identifying and handling:

* NULL values
* Duplicate records
* Invalid or inconsistent data
* Incorrect data types
* Missing information

### Measures & Metrics

SQL queries for calculating:

* Total sales
* Average sales
* Number of customers
* Number of orders
* Product-level metrics
* Customer-level metrics
* Key performance indicators (KPIs)

### Time-Based Analysis

Analysis of business performance across different time periods, including:

* Yearly trends
* Monthly trends
* Daily analysis
* Year-over-year comparisons
* Period-over-period comparisons

### Cumulative Analysis

Use of SQL window functions to calculate:

* Running totals
* Cumulative sales
* Cumulative averages
* Progressive performance trends

### Data Segmentation

Grouping customers and products into meaningful categories based on business rules and analytical criteria.

### Advanced SQL

The project also demonstrates concepts such as:

* `JOIN`
* `GROUP BY`
* `HAVING`
* `CASE`
* Subqueries
* Common Table Expressions (CTEs)
* Window Functions
* `ROW_NUMBER()`
* `RANK()`
* `DENSE_RANK()`
* `LAG()`
* `LEAD()`
* Aggregate Functions

## 🚀 How to Use

### 1. Clone the Repository

```bash
git clone https://github.com/Barin99/sql-data-analytics-project.git
```

### 2. Open SQL Server Management Studio

Connect to your SQL Server instance using SSMS.

### 3. Load the Dataset

Import the required CSV files from the `datasets` folder into your SQL Server database.

### 4. Run the SQL Scripts

Open the SQL scripts from the `scripts` folder and execute them in SSMS.

You can run the scripts individually depending on the analysis you want to perform.
